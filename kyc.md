Got it — Jaumo not detecting/rejecting OBS Virtual Camera is a pretty common issue right now.
Jaumo’s camera access (especially during profile photo upload or video verification) can be picky with virtual cameras and emulators.
Quick Troubleshooting Steps (Try in Order)
Assuming you're using BlueStacks (most common method):
Start OBS Virtual Camera FIRST
Open OBS → set up your scene → click Start Virtual Camera (it should turn green/active).
Correct Camera Name in BlueStacks
Open BlueStacks → click the gear icon (Settings) → go to Devices tab.
Under Camera, select "OBS-Camera" (not "OBS Virtual Camera" — the exact name matters).
Save and fully restart BlueStacks (close it completely, then reopen).
Test the Camera
Before opening Jaumo, install a simple camera app inside BlueStacks (like the default Camera app) and check if OBS feed appears.
If it doesn’t show even there → the problem is OBS/BlueStacks, not Jaumo.
Extra Fixes
Run OBS as Administrator.
Restart your PC.
In BlueStacks Settings → Engine → try switching Graphics Renderer (OpenGL vs DirectX) and restart.
Make sure Jaumo has camera permission when it asks.
If you're trying the web version (if Jaumo has one in your region):
Go to jaumo.com in Chrome.
Click the camera icon in address bar → Site settings → Camera → select OBS Virtual Camera.
Disable Hardware Acceleration in Chrome (chrome://settings/system) — this fixes many virtual cam detection problems.
If It Still Rejects OBS Camera
Jaumo (like many dating apps in 2026) has improved detection for virtual/emulated cameras, especially during video verification. Some users report it simply refuses to use virtual sources now.
Best workaround for nice profile pictures (low risk):
In OBS, capture high-quality still photos or short clips of your scene.
Save them to your PC.
In BlueStacks → Jaumo → Edit profile → Add photo → Upload from gallery instead of using the camera.
This way you avoid the live camera detection completely for normal profile pics.
For video verification, it’s harder to reliably bypass without getting flagged.

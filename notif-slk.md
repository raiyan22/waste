2) Set Slack to use its own sound
Settings → Apps → Slack → Notifications.
Make sure the main Notifications toggle is ON.
Tap Notification categories (or tap each category like “Messages”, “Mentions”, etc.).
For each category you want sound for:
Tap the category → tap Sound.
Choose the sound you want for Slack.
Make sure vibration is OFF if you only care about sound.
3) Set Instagram to use a different sound
Settings → Apps → Instagram → Notifications.
Make sure the main Notifications toggle is ON.
Tap Notification categories (or each category like “Messages”, “Likes”, etc.).
For each category you want sound for:
Tap the category → tap Sound.
Choose a DIFFERENT sound than the one you picked for Slack.
Vibration: ON/OFF as you prefer.
4) Silence all other apps
For every other app you don’t want to hear (Messages, Gmail, games, shopping apps, etc.):

Settings → Apps → [App name] → Notifications.
Tap Notification categories (or tap each category).
For each category:
Tap Sound → select “Silent” (or “None”).
Set Vibration to OFF.
